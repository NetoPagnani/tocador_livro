# 📖 Tocador de Livro - Dom Casmurro

> Um web player de áudio interativo desenvolvido especialmente para a imersão na obra clássica "Dom Casmurro", de Machado de Assis.

🌐 **Acesse o aplicativo online:** [Tocador Dom Casmurro](https://tocadorlivro.netlify.app/)

---

## 🚀 Sobre o Projeto

Este aplicativo web foi desenvolvido originalmente durante o **Intensivão de JavaScript da Hashtag Treinamento**, mas passou por um processo de personalização e refatoração para se distanciar do escopo padrão do curso. 

A aplicação foi adaptada para funcionar como um reprodutor de audiolivro exclusivo para a obra **Dom Casmurro**, permitindo ao usuário navegar pelos capítulos, pausar, reproduzir, avançar ou retroceder as faixas de áudio através de uma interface intuitiva e dinâmica.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web nativas, sem a necessidade de frameworks complexos:

* **Estruturação:** HTML5 (estruturação semântica dos elementos de áudio e controle).
* **Estilização:** CSS3 (layout responsivo e estilização customizada dos botões de reprodução).
* **Lógica e Interatividade:** JavaScript Vanilla (manipulação do DOM, controle do objeto `Audio` nativo e sincronização de faixas).

## ✨ Funcionalidades e Customizações

- [x] **Controle de Faixas:** Botões funcionais de Play, Pause, Próximo Capítulo e Capítulo Anterior.
- [x] **Identidade Própria:** Interface visual e temática totalmente customizada para a obra literária, diferenciando-se do design padrão do treinamento.
- [x] **Navegação Dinâmica:** Atualização textual automática na tela indicando qual capítulo está sendo reproduzido.
- [x] **Deploy Contínuo:** Hospedagem realizada de forma rápida e gratuita através da plataforma **Netlify**.
